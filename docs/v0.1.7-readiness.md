# Humhum v0.1.7 beta verification

Target: Apple Silicon Macs, macOS 13+, English transcription. This release includes only changes merged into main before the release PR; pending dependency PRs are excluded.

## Changes since v0.1.6

- Bound transcription worker and model memory lifetimes, including releasing model resources after inference.
- Upgrade Whisper and transcribe the complete recording with safe segment reads.
- Update microphone capture and resampling; fail closed on resampling errors.
- Fix opening the source and license link in the browser.
- Update the Tauri, React, networking, and dependency stacks, including Tokio and webpki security patches. Source builds now require Node.js 24 and Rust 1.90+.

## Local automated checks — 2026-10-28

- 168 frontend tests and the frontend production build passed on Node.js 24.
- 378 Rust unit tests and 2 integration tests passed; 6 tests were intentionally ignored.
- All 26 release-automation tests passed.
- Notices regenerated for 337 Rust components and 8 npm production dependencies; notice hash verification passed. No dependency versions changed in the release PR.
