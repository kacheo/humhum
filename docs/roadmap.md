# Roadmap

Wipzi's first public beta targets Apple Silicon Macs running macOS 13 or later, with English transcription.

Near-term priorities:

- Improve first-run permission recovery and reliability based on beta reports.
- Verify the API-key E2E case in a normal macOS test session before enabling it in the default suite.
- Evaluate Intel builds with real Intel Mac testing before claiming support.

These are priorities, not release-date commitments. Open an issue before starting a substantial change.
