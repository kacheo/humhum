# Humhum v0.1.6 beta verification

Target: Apple Silicon Macs, macOS 13+, English transcription. v0.1.6 fixes activation of a changed onboarding shortcut and adds recording/transcription/error feedback. This is an installer beta; review dictated text before sending it.

## Confirmed checks

- The maintainer confirmed the corrected Try it step with a changed shortcut and real speech transcription in the signed local candidate.
- 164 frontend tests, 371 Rust unit tests plus 2 integration tests (5 intentionally ignored), 20 release tests, frontend/native builds, and the default native E2E suite passed.
- Native E2E verifies a custom shortcut is persisted while onboarding is still incomplete, before Try it is displayed. Modifier-only shortcuts are covered by frontend tests; the embedded WebDriver omits modifier flags for those synthetic events, so native E2E uses Option+K.
- Dependency notices match the locked inputs, including the Cargo manifest. Full-history Gitleaks, workflow validation, and CI security checks passed.

The release artifact's notarization, Gatekeeper, source-tag, and checksum verification will be recorded here after downloading the exact draft-release installer. Do not treat the earlier locally signed, unnotarized DMG as the public release artifact.

## Remaining manual coverage

The full [macOS smoke checklist](manual-test-checklist.md) is not marked completely passed. Fresh-permission recovery, both real Whisper models, five-minute limits, real Ollama/cloud-provider combinations, offline raw transcription, and upgrade grant retention have not all been independently confirmed for the final installer. Automated fixture tests and the maintainer's core dictation check are narrower evidence.

The prior [source-release record](humhum-readiness.md) and [Wipzi audit](public-readiness.md) remain historical evidence. Development-tool dependency advisories and unmaintained Rust warnings remain tracked; successful Security CI does not imply every development dependency is advisory-free.
