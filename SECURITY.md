# Security

Please report suspected vulnerabilities through GitHub's **Report a vulnerability** flow for `kacheo/wipzi`. Do not include real API keys, recordings, or transcripts in a report. For issues that are not sensitive, open a regular GitHub issue.

Release builds are signed and notarized. Download installers from this repository's GitHub Releases page and verify that the release links to the corresponding source tag.

## Supported versions and scope

During beta, security fixes target the latest supported release. Include the app version, macOS version, reproduction steps with synthetic data, and the affected permission/network path. Avoid posting sensitive findings in public issues. There is no guaranteed response-time SLA.

Private reporting must be enabled in repository settings when the repository becomes public; this file alone does not enable the reporting flow. See [the readiness record](docs/public-readiness.md) for launch status and the reviewed dependency findings.
